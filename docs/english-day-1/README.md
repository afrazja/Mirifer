# English Day 1: "Lost luggage at the airport" (rebuild, draft v1)

Status: **writing, then review, then owner approval.** Day 1 was built before the one-world method,
in one version. After the review of Day 1 against Days 2–3 (in chat), the owner chose to rebuild it
in **two versions, five modules each**, keeping what works, and to keep it the shortest day.

- `world.md`: the Day 1 world (written down from the built conversation, consistent with Days 2–3).
- `listening.md`: a new Intermediate question set for the built conversation.
- `phrases-and-messages.md`: Natural phrases (a new A2 set), traps, Say it in English (both sets),
  voice messages.
- `conversation.md`: Role-play with a twist (the learner's own lost bag at the baggage desk).
